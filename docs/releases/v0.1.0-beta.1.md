# pmask 0.1.0-beta.1

The first public release of `pmask`. `pmask` redacts the `/proc` metadata
of a whole process tree while every program keeps its real arguments and
environment.

This is a beta: the mechanism and the limits are documented, the suites
in `tests/` and `vm/` pass, and the CLI and the library API may change
before `0.1.0`.

## Binaries

| file | system |
| --- | --- |
| `pmask-x86_64-unknown-linux-musl`, `pmaskd-x86_64-unknown-linux-musl` | Linux x86-64 |
| `pmask-aarch64-unknown-linux-musl`, `pmaskd-aarch64-unknown-linux-musl` | Linux ARM64 |

Each binary is static (musl). `pmask.1` and `pmaskd.8` are the manual
pages. `pmask-0.1.0-beta.1-<target>.tar.gz` adds the completions and the
systemd units.

## Install

```sh
curl -fLO https://github.com/Azathothas/pmask/releases/download/v0.1.0-beta.1/pmask-x86_64-unknown-linux-musl
chmod +x pmask-x86_64-unknown-linux-musl
./pmask-x86_64-unknown-linux-musl --version
```

## Check a download

```sh
sha256sum -c --ignore-missing SHA256SUMS
gh attestation verify pmask-x86_64-unknown-linux-musl --repo Azathothas/pmask
```

## Breaking

None. This is the first public release.

## What to test

- `pmask --label ci-runner ./deploy.sh --token "$TOKEN"` on a host where
  `kernel.yama.ptrace_scope` is 0 or 1.
- `pmask probe` and `pmask doctor --require redact,exact` on the kernels
  you care about.
- `pmaskd` with a socket in a private directory, and `pmask --daemon`.
- `--secret`, `--isolate`, `--no-dumpable` and `--rexec` on the
  filesystems you use.

## Limits

The limit table in `README.md` is the contract. Root on the host sees that
a pid exists and can read its memory; `cmdline` and `comm` are readable
by every local account; `environ`, `exe`, `maps` and `fd/*` are readable
by the same uid unless `--no-dumpable` is set.

## What to report

Open an issue with `pmask --version`, `pmask probe`, the kernel and the
command. Report a vulnerability through `SECURITY.md`, not a public
issue.
