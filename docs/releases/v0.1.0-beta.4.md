# pmask 0.1.0-beta.4

`0.1.0-beta.4` is the detection-audit follow-up to `0.1.0-beta.3`. The
redaction engine is unchanged. The supervisor no longer keeps the real
argv and environment at rest, the fallback window shapes no longer carry
their old fingerprints, `--exec-once` covers a settled re-exec, a 32-bit
image is refused by default, and `--stealth` composes the strongest shape
for the host's `/proc` policy.

## Changes

- The supervisor scrubs the parent's argv and environment copies after
  the fork and zeroes each per-exec copy when the redaction block is
  built. It stays dumpable at rest, so a host whose `/proc` uses
  `hidepid=invisible` no longer sees it as a hidden pid. `--no-dumpable`
  still pins it non-dumpable.
- `--keep-env=NAME` moves the kernel's environment window onto a compact
  kept-only span. `/proc/<pid>/environ` is the named variables, with no
  NUL padding from the original extent.
- `--no-exact` and a refused `PR_SET_MM_MAP` present the label padded
  with spaces and one final NUL, and a decoy environment (or the
  `--keep-env` variables). The old NUL run and all-NUL block are gone.
- `--exec-once` syscall-supervises a settled tracee, so its later exec is
  redirected to the cached image. `exe` is the guarded temporary file,
  not the real binary.
- A 32-bit (foreign-ABI) image is refused before it runs. `--allow-foreign`
  restores the documented unredacted run and the summary counts it.
- `--stealth` composes `--rexec`, `--watch-rename`, and `--no-dumpable`
  unless `/proc` uses `hidepid=invisible`. It prints the trade it chose.
- `pmask probe` has a `proc hidepid policy` row. `--require=hidepid`
  reports a degraded policy with exit 3.
- The isolate run prints that it is namespace-only. The README says
  `--isolate=none` still redacts and that the network identity is not
  hidden without `--isolate=net`.
- The supervisor's at-rest copies in the CLI, the runner and the daemon
  job are scrubbed. The daemon's job tracer keeps the daemon
  non-dumpable, because the daemon holds the job environment for its
  life.

## Tests

The new and updated fragments are `tests/qa.d/62.sh` (stealth and
hidepid), `tests/qa.d/39.sh` (dumpable supervisor at rest),
`tests/qa.d/40.sh` and `tests/qa.d/41.sh` (the new fallback shapes),
`tests/qa.d/45.sh` and `tests/qa.d/61.sh` (exec-once), and
`tests/qa.d/49.sh` (32-bit refusal, with a `cc -m32` fallback when the
i686 testcases binary is absent). `tests/core.sh` K15/K15b assert the new
window presentation.

The re-measurement is `evidence/stealth/`. It carries the case records,
the compact matrix, the hidden-pid run and the launch-window logs.

## Limits

The launch window is unchanged. The same-uid memory read is open in the
default mode and on a `hidepid=invisible` host under `--stealth`. Root
reads every mode. The network identity is unchanged unless
`--isolate=net` is used. A 32-bit image is refused, not redacted. The
supervisor's `exe` still names the pmask binary.
