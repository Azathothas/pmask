# pmask 0.1.0-beta.4

`0.1.0-beta.4` is the detection-audit follow-up to `0.1.0-beta.3`.
The core redaction engine remains unchanged.
This release scrubs at-rest supervisor copies, removes fallback window fingerprints, extends `--exec-once` to settled re-execs, refuses 32-bit images by default, and adds `--stealth`.

## Breaking

- `pmask` refuses 32-bit (foreign-ABI) images before execution instead of running them unredacted. Pass `--allow-foreign` to restore the unredacted run.

## Changes

- The supervisor scrubs its parent `argv` and environment copies right after fork and zeroes each per-exec copy after building the redaction block.
- The supervisor stays dumpable at rest by default. Hosts with `hidepid=invisible` no longer flag the supervisor as a hidden pid. `--no-dumpable` still pins the supervisor non-dumpable.
- `--keep-env=NAME` moves the kernel environment window onto a compact span containing only the kept variables, without trailing NUL padding.
- `--no-exact` and refused `PR_SET_MM_MAP` runs pad the label with spaces plus one final NUL and write a decoy environment (or `--keep-env` variables). The old NUL run and all-NUL block are removed.
- `--exec-once` keeps settled tracees syscall-supervised and redirects later execs to the cached temporary-file carrier. `/proc/<pid>/exe` points to the carrier instead of the real binary.
- `pmask` refuses 32-bit images before execution. `--allow-foreign` restores unredacted execution and records the count in the session summary.
- `--stealth` composes `--rexec`, `--watch-rename`, and `--no-dumpable` unless `/proc` mounts `hidepid=invisible`. `pmask` prints the selected trade once.
- `pmask probe` adds a `proc hidepid policy` row. `pmask doctor --require=hidepid` exits 3 on a degraded policy.
- Isolate runs state explicitly that isolation is namespace-only. `README.md` documents that `--isolate=none` still redacts and that network identity requires `--isolate=net`.
- The CLI, runner, and daemon job scrub at-rest supervisor copies. The daemon job tracer keeps `pmaskd` non-dumpable because `pmaskd` holds the job environment for its lifetime.

## Tests

New and updated QA fragments:

- `tests/qa.d/62.sh`: `--stealth` and `hidepid` policy checks.
- `tests/qa.d/39.sh`: dumpable supervisor at rest.
- `tests/qa.d/40.sh` and `tests/qa.d/41.sh`: updated fallback window shapes.
- `tests/qa.d/45.sh` and `tests/qa.d/61.sh`: `--exec-once` settled re-exec caching.
- `tests/qa.d/49.sh`: 32-bit refusal with a `cc -m32` fallback when the i686 probe binary is absent.
- `tests/core.sh` `K15` and `K15b`: updated window presentation assertions.

Re-measurement logs live in `evidence/stealth/`.
That directory holds the case records, compact matrix, hidden-pid run, and launch-window logs.

## Limits

- The launch window is unchanged.
- Same-uid memory reads remain open in default mode and under `--stealth` on `hidepid=invisible` hosts.
- Root can inspect every mode.
- Network identity stays unchanged unless `--isolate=net` is set.
- `pmask` refuses 32-bit images rather than redacting them.
- The supervisor's `/proc/<pid>/exe` still names the `pmask` binary.
