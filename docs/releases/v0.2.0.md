# pmask 0.2.0

`0.2.0` introduces execution profiles (`auto`, `single`, `tree`, `tee`, `compat`), a zero-supervisor in-place single-process masking engine (`TracerPid: 0`, `Threads: 1`), caller-opened `--secret-fd` delivery, live `/proc` + `/proc/<pid>/mem` auditing (`--audit`), host/tradeoff introspection (`--explain`), a versioned `pmask-profile/1` export (`--profile-json`) for `psgen`, private file-backed `--rexec-mode=path` staging, and roughly 2x faster startup on the tuned/default hot path.

Release artifacts ship as static musl binaries for x86-64 and ARM64 on **GitHub Releases only** (not published to crates.io; `crates-io = false` in `Cargo.toml`) under the 0BSD license.

## Honest scope

`pmask` targets **9+/10 confidentiality and low-residue execution against a same-uid local observer, not root**. Root on the host, `CAP_SYS_PTRACE`, kernel modules, eBPF/perf tracers, hypervisors, and hardware TEE adversaries remain explicitly out of scope. See [`docs/PROFILES.md`](../PROFILES.md) for the full threat boundary, `EACCES` vs helper-uid/subuid tradeoff, and residual risks table.

## Breaking

These are intentional beta default upgrades moving `pmask` from metadata-only defaults to strong same-uid confidentiality out of the box:

- **Default profile is now `--profile auto`**:
  - For direct native ELF binaries, `auto` selects `single` (in-place masked exec with zero persistent supervisor, `TracerPid: 0`, `Threads: 1`, `--rexec` with `--rexec-mode=auto`, `PR_SET_DUMPABLE=0`, and `RLIMIT_CORE=0`; pass `--encrypt-memory` to additionally seal the transient helper's in-flight buffers).
  - For shells, launchers, `#!` scripts, and tree flags, `auto` selects `tree` (single-threaded supervisor with `--rexec` for ELF targets, `PR_SET_DUMPABLE=0`, and `--encrypt-memory`).
  - Pass `--profile compat` to restore legacy `v0.1.0` metadata-only dumpable defaults (no forced `--rexec`, no forced `--no-dumpable`, no forced `--encrypt-memory`), or opt out individually with `--allow-dumpable` and `--no-rexec`.
- **Label impersonation policy enforced by default (exit 2)**:
  - Labels and `--comm` / `--parent-label` values using kernel-thread bracket syntax (`[...]`, e.g. `[kworker/0:0]`) or matching critical system services (`sshd`, `systemd`, `init`, `cron`, `crond`, `systemd-journald`, `systemd-udevd`, `udevd`, `dbus-daemon`, `polkitd`, `auditd`, `rsyslogd`, `syslogd`) are now refused with exit status `2`.
  - Pass `--allow-impersonation` to override explicitly.
- **Concise one-screen `--help` by default**:
  - `-h`, `--help`, and `pmask help` now print a concise one-screen overview (`<= 45` lines).
  - Use `--help=all` or `pmask help all` for the complete flag reference, and `--help=<topic>` or `pmask help <topic>` (`profiles`, `redact`, `secrets`, `isolate`, `daemon`, `audit`, `report`, `short`, `all`) for individual sections.
- **Fail-fast `--keep-env NAME cmd` space-form trap (exit 2)**:
  - Passing `--keep-env FOO /bin/cmd` or `--keep-env FOO -- /bin/cmd` (space-separated variable name instead of `--keep-env=FOO`) now fails fast with exit status `2` and prints the corrected `--keep-env=FOO` syntax instead of attempting to execute `FOO` as the command.
- **Additional `--daemon` local-only refusals (exit 255)**:
  - `--daemon` now also refuses `--secret-fd`, `--profile single`, and `--profile tee` alongside `--secret`, `--isolate`, `--no-redact`, `--hide-pid`, `--encrypt-memory`, `--image`, `--image-from-fd`, and `--report*`.

## Highlights

- **Execution profiles (`--profile auto|single|tree|tee|compat`, `--auto`, `--follow`)**:
  - `single`: In-place masked `execve`/`execveat` via a transient double-forked helper (`PR_SET_PTRACER` compatible with `yama.ptrace_scope=1`) that completes redaction, cleans up any staged carrier, and detaches and exits immediately. The payload keeps its original PID with `TracerPid: 0`, `Threads: 1`, `Seccomp: 0`, `NoNewPrivs: 0`, `PR_SET_DUMPABLE=0`, `RLIMIT_CORE=0`, and `--rexec`.
  - `tree`: Single-threaded (`Threads: 1`) supervisor covering full descendant trees, shells, and `#!` scripts with `--rexec`, `--no-dumpable`, and `--encrypt-memory` enabled by default.
  - `tee`: Composes redaction with user, pid, and mount namespaces plus a private `/proc`, private `/tmp`, and `cwd=/` normalization by default; fails closed when unprivileged user namespaces are unavailable.
  - `compat`: Legacy `v0.1.0` flag-driven defaults.
- **Caller-opened descriptor secret delivery (`--secret-fd [NAME=]N`)**:
  - Preserves caller-opened file descriptor `N` across exec at its existing number (clearing `FD_CLOEXEC`) and exports `PMASK_SECRET_FD=N` (unnamed) or `PMASK_SECRET_<NAME>=N` (named) in the payload's real environment.
  - Validates that `N` is open before exec (exit 2 otherwise), enables `--no-dumpable` unless `--allow-dumpable` is passed, and works across `single`, `tree`, `tee`, `compat`, isolate, and plain modes.
- **Standalone live audit engine (`--audit`, `--pid`, `--observer`, `--json`, `--token-env`, `--token-fd`, `--real-exe`, `--real-cwd`, `--allow-memfd`)**:
  - `pmask --audit` (with no `COMMAND` or `--pid`) launches a live masked child holding a fresh synthetic token on its heap, probes every `/proc/<pid>` surface plus a bounded full-VMA `/proc/<pid>/mem` scan (up to 64 MiB), verifies invariants `INV-1` through `INV-10`, cleans up, and exits `0` on pass or `1` on failure.
  - `pmask --audit --pid PID` audits any target process from a `same-uid` (default) or `other-uid` perspective and emits deterministic `pmask-audit/1` JSON with `--json`. Raw secret bytes are scrubbed and never emitted.
- **Host & profile explainer (`--explain [--profile NAME] [--label NAME] [--json]`)**:
  - Reports the named observer (`same-uid local observer, no root`), explicit non-goals, detected host capabilities (including `/proc/self/uid_map` and `/etc/subuid` helper-uid readiness), hidden surfaces, the `EACCES` tradeoff, and honest residuals.
- **Versioned profile export for `psgen` (`--profile-json`)**:
  - Emits the `pmask-profile/1` JSON contract for a live `--pid PID` or as a static template for `--profile`/`--label`, including `psgen_hint` alignment fields and `safety.token_present` / `safety.token_sha256` with zero raw secret bytes (`INV-8`).
- **Private path-staged execution (`--rexec-mode=auto|path|memfd`, `--no-rexec`)**:
  - `--rexec-mode=path` (preferred by `auto`) stages a private `0500` copy named `<sanitized_label>` inside a private `0700` directory and unlinks it immediately after exec, leaving zero `/memfd:` fingerprint in `/proc/<pid>/exe`, `maps`, `smaps`, and `auxv`. Falls back to sealed `memfd` on `noexec` mounts under `auto`.
- **Process shape controls (`--cwd PATH`, `--parent-label NAME`, `--reparent`)**:
  - `--cwd` normalizes `/proc/<pid>/cwd` after resolving `COMMAND`.
  - `--parent-label` gives the `tree` supervisor a distinct label from the payload to avoid a supervisor/payload label twin.
  - `--reparent` double-forks a `single`-profile payload so it runs reparented to PID 1 (or the nearest subreaper) and returns `0` once masked exec detaches.
- **Performance (~2x faster tuned/default startup)**:
  - Zero-fork fast ptrace probe (`Caps::ptrace_usable_fast()`) on the hot path instead of running the full 8-probe `Caps::detect()` suite on every run.
  - Tighter seccomp BPF filters, batched tracee memory writes during exec completion, and single-threaded supervisor execution (`Threads: 1`) on the CLI redaction path.

## Bug fixes

- Fixed `--watch-rename` combined with `--no-dumpable` warning behavior so non-dumpable tracee `readlink` `EACCES` diagnostics report cleanly once per session.
- Fixed `pmask help <topic>` option-header parsing so compound headers such as `-l, --label NAME`, `--isolate[=LIST]`, and `--report=json` are indexed and printed accurately for every topic.
- Synced shell completions (`bash`, `fish`, `zsh`), `man/pmask.1`, `man/pmaskd.8`, `README.md`, and `docs/PROFILES.md` with all v0.2.0 options, profiles, refusal lists, and seven-surface `--no-dumpable` semantics (`environ`, `maps`, `auxv`, `exe`, `fd`, `cwd`, `mem`).
