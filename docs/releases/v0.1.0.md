# pmask 0.1.0

`0.1.0` is the first stable release of `pmask`.
This release consolidates all `v0.1.0-beta.4` and `v0.1.0-beta.5` stealth, isolation, and memory-hardening features, and closes all 20 open red-team, blue-team, and audit issues.
Release artifacts ship as static musl binaries for x86-64 and ARM64 on GitHub Releases under the 0BSD license.

## Breaking

- **32-bit images refused by default**: `pmask` kills 32-bit (foreign-ABI) execs before execution because 32-bit images cannot be redacted. Pass `--allow-foreign` to restore unredacted execution.
- **Non-dumpable default for `--secret` runs**: In redact mode, any `--secret` session now sets `--no-dumpable` on both the payload tree and the supervisor. Pass `--allow-dumpable` to keep the payload dumpable.
- **Refused unsafe flag combinations (exit 255)**:
  - `--exec-once` with `--no-dumpable`, `--hide-pid`, `--stealth` (on non-`hidepid` hosts), or a default non-dumpable `--secret` session.
  - `--watch-rename` (or `--watch-rename=strict`) with `--detach` or `--on-exit detach`. In the CLI, `--watch-rename` now defaults `--on-exit` to `wait`.
  - `--strict-exec` with `--detach`.
  - `--hide-pid` with `--no-follow`, `--detach`, or a `/proc` mount weaker than `hidepid=invisible` or `hidepid=ptraceable`.
  - `--daemon` with `--report`, `--hide-pid`, `--encrypt-memory`, `--secret`, `--isolate`, `--no-redact`, `--image`, or `--image-from-fd`.
  - `--audit` with stdout `--report=json` (use `--report-file` or `--report-fd`).
- **Library-level safety refusals**: `Mask::prepare` enforces the same refusals for `exec_once` + `no_dumpable`/`hide_pid`, `watch_rename` + `SessionEnd::Detach`, and `strict_exec` + `detach_after_first`.
- **Fail-closed `--rexec`**: Image placement failure exits 126 (or 127 when missing) instead of silently running the on-disk binary. Pass `--rexec-allow-disk` for explicit on-disk fallback.
- **Test hooks gated**: `PMASK_FAULT_*` and `PMASK_PROBE_*` switches require `--features test-hooks` and are compiled out of release builds.
- **MSRV**: Minimum Supported Rust Version is 1.87.

## Stealth, isolation, and memory hardening

- **Stack-region presentation block**: Exact mode places the presentation strings (`label\0`, plausible 110-byte decoy or kept `environ`, and `AT_EXECFN` label) inside the kernel `[stack]` region. `/proc/<pid>/stat` preserves `arg_end == env_start`, `start_stack < arg_start`, and an intact `[stack]` VMA.
- **Consistent `AT_EXECFN`**: `patch_stack_execfn` updates the tracee's initial stack auxiliary vector so `getauxval(AT_EXECFN)` matches `/proc/<pid>/auxv` in exact mode.
- **Clean `--no-exact` window**: `--no-exact` keeps the original `arg_lo..arg_hi` and `env_lo..env_hi` extents. The tracer pads the label with spaces plus one NUL and writes complete non-repeating decoy entries.
- **`--strict-exec`**: Refuses `#!` scripts, `vfork` children, settled re-exec bypasses, and any entry-redaction fallback by killing the tracee before execution.
- **`--stealth`**: Composes `--rexec`, `--watch-rename`, and `--no-dumpable` (keeping the tree dumpable on `hidepid=invisible` and `hidepid=ptraceable` hosts) and prints the chosen trade once.
- **`--hide-pid`**: Hides the tree from same-uid `/proc` readers on `hidepid=invisible` or `hidepid=ptraceable` mounts via `PR_SET_DUMPABLE=0`. Prints a runtime notice documenting cgroupfs and non-`/proc` syscall limits.
- **`--encrypt-memory`**: Seals supervisor at-rest `argv` and `environ` copies with XChaCha20-Poly1305 under a `memfd_secret` session key (or `mlock`'ed heap with a visible note). Marks the separate anonymous redaction block `MADV_DONTDUMP` without splitting `[stack]`.
- **`--watch-rename` and `--watch-rename=strict`**: Traps `prctl(PR_SET_NAME)` plus `open`, `openat`, `openat2`, and `creat` targeting `/proc/.../comm`. `--watch-rename=strict` adds write-syscall traps (`write`, `writev`, `pwrite64`, `pwritev`, `pwritev2`) to catch symlink aliases and transferred descriptors.
- **`--exec-once` fast path**: Installs an `execve`/`execveat` seccomp filter when `PTRACE_O_EXITKILL` is active and `--on-exit` is not `detach`, running settled tracees under `PTRACE_CONT`. Verifies temporary carriers before exec and prefers `$XDG_RUNTIME_DIR` over `/dev/shm`.
- **Probes and contract**: `pmask probe` and `pmask doctor --require` support `hidepid`, `hide-pid`, and `encrypt-memory`. `docs/INTEGRATION.md` specifies the binary and library adoption contract.

## Final v0.1.0 hardening fixes

- **Ptrace state-machine supervision**: `resume_state` now keeps `PTRACE_SYSCALL` for all non-`Run` states (`Swapped`, `Script`, `Foreign`). Keeping syscall supervision fixes failed-exec recovery, mid-exec signals, and `--exec-once` fast-path double stops. Non-leader `PTRACE_EVENT_EXEC` clears stale `pending_plaintext`, `!WIFSTOPPED` closes `report_fd`, and 32-bit refusal uses `self.refuse`.
- **`aarch64` syscall denial**: `Regs::deny_syscall` and `Regs::put` on `aarch64` write `-1i32` via `PTRACE_SETREGSET` (`NT_ARM_SYSTEM_CALL`) alongside `NT_PRSTATUS`. `--watch-rename` and `--watch-rename=strict` denials now work on ARM64.
- **`--watch-rename` hardening**: Path matching now normalizes repeated slashes, `.`, and `..` before checking `/proc/.../comm`. The x86-64 and i386 filter now traps `SYS_creat`. `pmask` also emits one warning per session when `readlink` fails with `EACCES` on a non-dumpable tracee.
- **`AT_EXECFN` NUL terminator**: Allocated the trailing NUL byte in `pres_bytes` and `plan_presentation`, preventing 16-byte alignment boundaries from bleeding into real `argv[0]` or kernel `AT_EXECFN`.
- **`--exec-once` carrier and scratch fixes**: Fixed the scratch-page collision at `base + 512` between env filler and the redirect path. Added `st_dev`, `st_ino`, and `ctime` to the source `Cache` key. Added a visible warning when `seal()` fails on a temporary carrier. Redirected carrier-reaper stdio to `/dev/null` and closed `reaper_fd` on `Image::drop`. Closed parent fd 200 after fork under `--exec-once`.
- **Supervisor memory and report hygiene**: Zeroized `original_argv` right after the plain-mode restore check and wrapped temporary secret/argument buffers in `Zeroizing`. Fixed `run.rs` to preserve `supervisor_non_dumpable` for `--report` and to run `prepare` -> `mask_self_opts` -> `spawn_prepared` without racing `PR_SET_DUMPABLE`. Added `Drop` cleanup on `ReportSink` for staged temp files, and surfaced `harden_self()` failures in `pmaskd` and `subcmd`.
- **Tracee path resolution and accounting**: Rewrote `/proc/self/` and `/proc/thread-self/` to `/proc/{pid}/` in `path_is_elf` and `elf_is_32`. Released `pending_plaintext` and fixed `stats.sealed` accounting on failed `Script` and `Foreign` execs.
- **Non-dumpable secret delivery and agent interop**: Cached `Tracee::syscall_site` before `PR_SET_DUMPABLE=0` and inherited it across forks so `--secret-close-on-exec` closes secret descriptors in descendants on non-dumpable `--secret` sessions, with a ptrace `CLONE_FILES` fallback when `kcmp(KCMP_FILES)` returns `EPERM`. Added `Peer::revalidate_for` in `src/agent.rs` so hardened non-dumpable `pmask run` clients succeed against policy-free `pmask agent` instances while `pidfd`/`proc_start` pinning and executable policies remain fail-closed.
- **Window fallback restoration**: Restored the space-padded label and decoy environment windows when `PR_SET_MM_MAP` fails with `EPERM`, and deferred `patch_stack_execfn` until relocation succeeds.
- **Help, completions, man pages, and docs**: Fixed `--no-dumpable` and `--strict-exec` help lines in `src/cli.rs` and synced `SHORT_HELP` and `doctor --require` in `src/subcmd.rs`. Updated `man/pmask.1`, `man/pmaskd.8`, shell completions, and repository docs to `0.1.0` in ASD-STE100 style.
